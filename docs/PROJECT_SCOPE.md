# Project scope

## Confirmed

- Master's project in Applied Investments at HEC Lausanne, University of Lausanne.
- Study a signal-based investment strategy in US equities.
- Use the professor-provided dataset.
- Measure alpha with the factor model specified by the professor.
- Respect historical information availability and avoid biased evaluation.

## Pending

- Dataset contents, sample period, and field definitions.
- The exact factor specification and evaluation conventions.
- Permitted portfolio constraints, including whether shorting is allowed.
- Signal definitions, modeling approach, implementation language, and validation design.

The repository name describes the intended research direction. It does not commit the project to machine learning or to any particular prediction method.
